# Benchmark harness — plan

`confidence: INFERRED`

## Where it lives

- `benchmarks/__init__.py` — version constant and `PAY_GATE_ENV = "DUMMYINDEX_BENCH_ALLOW_PAY"` (benchmarks/__init__.py:33-35).
- `benchmarks/arms.py` — arm enum, AGENTS.md rendering, pinned-clone cache, workspace materialization, workflow markers (benchmarks/arms.py:39-343).
- `benchmarks/runner.py` — opencode transport port (default model `opencode/x-preview-f-free`), pay gate, per-run sandboxes, JSONL append (benchmarks/runner.py:41-325).
- `benchmarks/telemetry.py` — tolerant stream/export parsers funneled into one `RunMetrics` shape (benchmarks/telemetry.py:33-234).
- `benchmarks/enrich.py` — phase-0 council-loop driver; `cmd_enrich` unions both suites' (repo, commit) targets and dedupes across the union (benchmarks/enrich.py:41-298; benchmarks/__main__.py:462-469).
- `benchmarks/gates.py` — pre-registered thresholds and evaluation (benchmarks/gates.py:32-129).
- `benchmarks/report.py` — aggregation, latest-row dedupe, amortized-cost section, markdown rendering (benchmarks/report.py:28-255).
- `benchmarks/__main__.py` — composition root: parser, seven subcommands (plan, run-repoqa, run-swebench, enrich, reset-cells, grade-swebench, report), cell orchestration, retry/parallelism, fault instrumentation, exit-code mapping (benchmarks/__main__.py:585-712).
- `benchmarks/suites/` — two dataset adapters behind one protocol: `repoqa.py`, `swebench.py`; shared `SuiteDataError` (benchmarks/suites/__init__.py:6-8).
- `benchmarks/scoring/` — pure graders `snf.py` / `snf_official.py`, patch extractor `swebench_patch.py`, docker wrapper `swegrade.sh`.
- `tests/benchmarks/` — offline deterministic unit tests; `fixtures/opencode_stream.jsonl` pins the telemetry event shape.
- Runtime artifacts live outside the package under gitignored `results/benchmarks/**`.

Dependency direction (acyclic): `__main__` → {suites, runner, arms, report, enrich}; suites → arms; enrich → arms + runner; report → gates; runner → telemetry. Heavy optional deps (`datasets`, `nltk`, tree-sitter grammar wheels) are imported lazily inside `__main__` command functions and scoring modules, so `python -m benchmarks plan` runs without them. All side effects cross process boundaries through injectable seams (`run_fn`, `cli_fn`, `stream_fn`, `copy_fn`, `indexer` parameters throughout arms/runner/enrich), which is what makes the offline test suite possible.

## Architecture in three sentences

`__main__.py` is the composition root: it converts CLI args into per-cell closures around `runner.run_one_task`, which shells out to `opencode run --format json --auto --pure` inside a per-run XDG sandbox, funnels stdout through `telemetry.metrics_from_stream`, and appends one row per cell via `append_row`. Each suite adapter owns dataset loading, seeded stratified subset selection, prompt construction, and workspace preparation delegated to `arms.prepare_arm_workspace` (shared pinned-clone cache + arm-local copies); scoring grades finished work as pure functions (`snf.py`, `snf_official.py`) or by handing patches to the external dockerized harness (`swebench_patch.py` + `swegrade.sh`). Cross-cutting consumers stay pure leaves: `report.load_rows → aggregate → render_report` derives summaries from rows and feeds `gates.evaluate_gates`, while `enrich.Enricher` reuses the same runner and arms primitives to build enriched caches before any sweep.

## Data model

No database; the ledger is append-only JSONL plus marker files on disk.

- `results/benchmarks/<suite>/runs.jsonl` — one sorted-key JSON object per cell (benchmarks/runner.py:318-325). Row identity: `suite, arm, task_id, repeat_index, workspace, prompt_sha256, wall_time_s, executed` (+ metrics when executed, else argv) (benchmarks/runner.py:99-115); suite extras `protocol/index_state/passed/best_similarity` (benchmarks/__main__.py:299-316) and terminal `error` rows (benchmarks/__main__.py:185-194). Readers keep only the latest row per `(arm, task_id, repeat_index)` (benchmarks/report.py:99-116); `reset-cells` rewrites the file with a `.jsonl.bak` backup (benchmarks/__main__.py:522-542).
- `results/benchmarks/enrichment/runs.jsonl` — cost ledger keyed `suite="enrichment"`, `arm="council"` with an `enrich_unit` payload; appended only for paid calls (benchmarks/enrich.py:9-12, 213-235).
- `results/benchmarks/swebench/preds-{run_id}.jsonl` — official-harness predictions: `instance_id = "{task}-{arm}-r{repeat}"` + `model_patch` (benchmarks/suites/swebench.py:141-147; benchmarks/__main__.py:397-406, 430-436).
- Markers encode workflow state: `.git/BI_BENCH_PINNED` (clone complete; holds commit), `.bi_bench_enriched` (JSON `{mode, units}`), `.bi_bench_ready` (`"{arm}:{commit}:indexed=N:mode=M"`) (benchmarks/arms.py:150-156, 214-215, 281-329).
- Trees: shared clones at `cache/repos/{slug}-{commit[:12]}` (benchmarks/arms.py:127-130); arm workspaces `{slug}-{commit}-{arm}[-r{repeat}]` under `results/benchmarks/workspaces/` (benchmarks/arms.py:276-279); opt-in raw stream dumps `<suite>/streams/` gated by `DUMMYINDEX_BENCH_KEEP_STREAMS=1` (benchmarks/runner.py:293-315); RepoQA dataset cache `results/benchmarks/cache/repoqa/repoqa-{version}.json` (benchmarks/suites/repoqa.py:53, 136-138); rendered reports `REPORT.md` / `ENRICHMENT.md`; grading output under `results/benchmarks/swebench/{run_id}/` (benchmarks/scoring/swegrade.sh:40-49).

## Key decisions

1. **Double pay gate, fail-closed** — spending requires `--execute` AND `DUMMYINDEX_BENCH_ALLOW_PAY=1`, enforced redundantly at CLI dispatch, in every command, and inside `run_one_task` itself so library callers cannot bypass it (benchmarks/__main__.py:142-144; benchmarks/runner.py:224-229). Decided: either gate alone admits accidental spend; `PayGateError` bypasses retries entirely because a gate violation is policy, not flaky transport (benchmarks/__main__.py:174-175).
2. **Shared-base / single-delta AGENTS.md** — both arms share byte-identical `NEUTRAL_BASE`; the context arm appends exactly one navigation section; the file is written last so ingest bootstrap cannot contaminate the delta (benchmarks/arms.py:58-105, 327-329). Decided against whole-file-per-arm replacement: an earlier design turned the measurement into an ablation ("index INSTEAD OF normal scaffolding") instead of a delta ("baseline PLUS the index") (benchmarks/arms.py:6-10).
3. **Enrich-once inheritance with stamped provenance** — the context arm inherits an enriched cache verbatim (re-ingesting would discard curated work); absent enrichment it ingests a backbone; the baseline arm always gets `.context/` stripped post-copy. Every row records `index_state` so backbone-era and enriched-era measurements stay separable, and `reset-cells --index-state` drops stale-condition rows (benchmarks/arms.py:306-325; benchmarks/__main__.py:515-543).
4. **Cost accounting split** — enrichment calls flow through the standard runner under `suite="enrichment"` into their own ledger, surfaced by report only under the `"__enrichment__"` key as an amortized-cost section that gates never see (benchmarks/enrich.py:9-12, 224-235; benchmarks/report.py:174-180, 235). Decided: folding one-time index-build cost into per-task metrics would corrupt both efficiency numbers and gate math; the ledger deliberately records only paid calls.
5. **Never reimplement official grading where comparability matters** — RepoQA's function protocol is a faithful BLEU port with two documented divergences (modern grammar wheels instead of the legacy bundle; loud failure on query-compilation errors) (benchmarks/scoring/snf_official.py:17-27); SWE-bench grading is outsourced entirely to the dockerized harness behind a thin auditable wrapper (benchmarks/scoring/swegrade.sh:2-9). The `name` protocol keeps the substring rule unnormalized beyond casefolding for leaderboard comparability (benchmarks/scoring/snf.py:3-10).
6. **Tolerant telemetry with anti-double-count rules** — unknown event shapes never crash parsing; usage dedupes per message id (last observation wins) and anonymous observations take the largest single value rather than a sum; cost takes the cumulative max; tool wrappers without names are not counted (benchmarks/telemetry.py:14-24, 133-176). Zero-event streams are hard `RunnerError`s so a broken transport can never masquerade as an arm result (benchmarks/runner.py:266-271).
7. **Determinism and resume everywhere** — seeded subsets are stable across input orderings (per-group sampling in repoqa, round-robin over pre-shuffled pools in swebench) (benchmarks/suites/repoqa.py:202-222; benchmarks/suites/swebench.py:89-112); sweeps skip cells already present in runs.jsonl (benchmarks/__main__.py:126-139, 321-336); interrupted enrichment resumes from the council frontier or skips via markers; full (non-shallow) clones because arbitrary pinned commits and SWE-bench grading need reachable history (benchmarks/arms.py:143-145).
8. **Concurrency hygiene** — every paid run gets its own sandbox root (shared opencode state databases deadlock with "database is locked") (benchmarks/runner.py:124-131); worker cold-starts stagger `(slot % 8) × 3 s`; workspaces materialize via tmp-dir + atomic rename with explicit lost-race handling (benchmarks/__main__.py:244-247; benchmarks/arms.py:160-185). Row safety is layered: `_ROW_LOCK` serializes the in-memory result/prediction lists (benchmarks/__main__.py:147, 213-214, 398); JSONL integrity rests on each `append_row` being a fresh `open("a")` plus a single write per row, not on the lock.
9. **Resilient cells, explicit holes** — transport-class failures (`RunnerError`, `WorkspaceError`, `OSError`) retry 3× with 20 s backoff, then append an explicit `error` row so the log shows the hole instead of silently pretending the cell ran (benchmarks/__main__.py:150-196). Exit-code mapping: pay/transport errors → 3, malformed suite data → 4 (benchmarks/__main__.py:701-708).

Load-bearing: the single-delta contract (#2) and `index_state` stamping (#3) carry the entire validity of the comparison; the telemetry dedup rules (#6) carry every efficiency number; the pay gate (#1) carries spend safety.

## Open questions

- **`benchmark_smoke` marker is registered but unused.** pyproject.toml:86 declares it (with `--strict-markers`, pyproject.toml:81) and feature.json's summary cites it as the opt-in mechanism, but no test under tests/benchmarks/ applies `pytest.mark.benchmark_smoke` or a module-level `pytestmark`. Smoke validation currently happens manually per benchmarks/README.md:170-181 (low-confidence catalogued doc; content re-verified directly against the file). Doc-vs-code conflict: the summary overstates pytest integration.
- **Dry-run rows count toward resume-skip.** `run-repoqa`/`run-swebench` dry-runs append `executed: false` rows to the same runs.jsonl (benchmarks/__main__.py:316, 407), and `_done_cells` does not filter on `executed` (benchmarks/__main__.py:126-139) — a prior dry run marks cells done and a later `--execute` sweep skips them unless `reset-cells` clears the log first. Intent unclear: convenient resume or footgun.
- **Type annotation lie in repoqa adapter.** `prepared_for_task` is annotated `-> Path` but returns the `PreparedWorkspace` from `prepare_arm_workspace` (benchmarks/suites/repoqa.py:236-253); its swebench twin honestly returns `.path` (benchmarks/suites/swebench.py:120-138). Callers use `prepared.path`/`prepared.index_mode` (benchmarks/__main__.py:272-302), so runtime behavior is consistent — but the annotation misleads any new caller.
- **`supervise.sh` referenced by committed docs but untracked.** RUN_LATER.md drives sweeps through `results/benchmarks/supervise.sh` (benchmarks/RUN_LATER.md:46-51; medium-confidence catalogued doc; file existence verified on disk). The script lives under gitignored `results/` (`.gitignore:37`), outside this feature's file set — a fresh clone cannot reproduce the documented supervisor. Ownership/reproducibility unresolved.
