## Data integrity

- **[HIGH]** `pipeline/io/cache.py:107-121,260-282` + `extract/generic.py:68,93` + `extract/__init__.py:165-172` — the cache key is content-only but the payload carries its writer's `source_file` and file-node id, so a byte-identical sibling, a renamed file or a moved checkout loads another path's result (22 of 23 empty `__init__.py` have no node; renamed `b.py` still emits `a.py`; `python_dispatch.py:436-437` then skips them silently). Fix: name entries `sha256(repo-relative path + "\0" + content)` inside `load_cached`/`save_cached`, not in `file_hash` (`--changed` reuses it, `context/build/incremental.py:304`).
- **[MEDIUM, Windows]** `export/storage.py:209-225` — `_atomic_write` does a bare `replace` (`:222`) with no `PermissionError` retry, so an open `read_graph_payload` handle aborts the publish with a raw `PermissionError`, not `GraphStorageError`. Fix: copy the `cache.py:162-171` backoff.
- **[MEDIUM]** `export/storage.py:187-206` — greedy byte packing shifts every later shard boundary on one insert or delete: 0 of 12 shards reused, ~11.5 MB of new committed blobs per graph-changing rebuild. Fix: content-defined cut points with the byte cap as backstop (see conflict (d)).
- **[LOW-MED]** `pipeline/io/cache.py:195-237` — the version stamp is per directory, so an older install still extracting after a newer one scoped the dir writes entries that are reused later; contradicts `spec.md:7` (never reuse an older extractor's output). - **[LOW]** `context/build/communities.py:76-113,182,209` — `_pagerank` byte stability is inherited from `list(g)` insertion order (`:89`), not enforced; the 0.1 test weight rests on a name heuristic with no knob, and `seed-rank.json` rows don't record it. Watch seam, not a live bug.

## Security

- **[HIGH]** `pipeline/io/cache.py:296-311` — `save_cached` writes a fixed `<hash>.tmp` (`:297`) via plain `write_text` (`:299`): a committed link at that name makes the first build overwrite its target outside the repo (hard-link probe overwrote it; POSIX checkouts materialize symlinks), and two same-hash writers share one tmp. Scoping never removes it (`:217`). Fix: `_write_bytes_atomic` (`:144-174`), drop the `copy2` fallback (`:307`), make the save best-effort.
- **[HIGH]** `pipeline/io/cache.py:195-282` — a hostile checkout commits `<sha256(file)>.json` plus an `extraction-version` equal to the running release: scoping deletes 0 (`:209-210`), the guard (`:240-257`) checks only node `id`, so the entry loads as `parsed` (probed), survives `rebuild --full`, and carries free-text labels into agent context; malformed edges/raw_calls crash `extract/__init__.py:210,286,296,306`. Fix: HMAC each entry with a per-user secret kept outside the worktree; validate edge/raw_call/label types; lstat + byte-cap the read (`:272-275`).
- **[MEDIUM]** `pipeline/io/cache.py:61-77` + `languages/{dart,blade}.py:21`, `{go,julia,zig}.py:27`, `{rust,elixir,verilog}.py:28`, `powershell.py:32` — no per-file size cap and every file is memoized for the build; those 9 extractors read disk directly, so the single-read seam is partial. Fix: cap inside `read_source_bytes`, route all extractors through it.
- **[MEDIUM]** `extract/languages/dart.py:39-41,68-70` — `^\s*` under `MULTILINE` plus the cross-line `(?:\w+\s+)+` repeat is quadratic (×4 time per ×2 size); `blade.py` rebuilds its id set per match. Fix: `[ \t]` classes, bounded repeat, size cap, running id set.
- **[MEDIUM]** `extract/__init__.py:371-379` — the default `collect_files` branch lets `rglob` descend Windows junctions and emit escaping leaves (probed); the follow branch (`:380-412`) misses junctions and keeps no visited set. Exposure: `__main__` and the public export only (builds use `detect`). Fix: reuse `detect.py`'s containment.
- **[LOW]** `export/storage.py:414-416,463,481,497` + `pipeline/io/cache.py:124-141,206-215` — reader caps come from the committed manifest's own `max_file_bytes` with no total ceiling and the plain read is uncapped; the cache dir is never lstat/reparse-checked outside `validate_context_destination`. Fix: reader-side ceiling + `sum(bytes)` check; lstat the dir in `cache_dir()` and scoping.
