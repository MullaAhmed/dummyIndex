## Security

- `dummyindex/context/claude_settings.py:39-50,175-179`, `dummyindex/context/claude_plugins.py:113-123,147-154`, `dummyindex/context/default_plugins.py:506,532,544`, `dummyindex/cli/equip/install.py:171-178`, `dummyindex/context/domains/equip/lifecycle/status.py:409-425`, `dummyindex/context/domains/equip/lifecycle/remove.py:98-104` — **Missing:** a link check before the settings read-modify-write. A repo-committed `.claude/settings.json` symlink to `~/.claude/settings.json` is read through by `load_settings`, and then the rename in `write_settings` replaces the link with a regular in-repo file holding the user's global `env`/`permissions`, ready to be committed. This runs unattended in default-plugin wiring during `dummyindex install`/`ingest` (`dummyindex/cli/init.py:73`, `dummyindex/installer/install/project_init.py:371`). — **Mitigation:** apply only (`dummyindex/cli/equip/dispatch.py:617-624`); none for `equip install`, default-plugin wiring, or `equip uninstall`/`remove`. — **Fix:** put one fail-closed check inside `load_settings`/`write_settings`: run `atomic_io.is_link` (`dummyindex/context/domains/atomic_io.py:16-35`) on every component below the file's base (project root, or `~/.claude` for user scope) and refuse on a hit.
- `dummyindex/context/default_plugins.py:173-193,404-408,646-667,353-370,399-408` — **Missing:** a pin on the code-running default plugins. `caveman@caveman` and `i-have-adhd@i-have-adhd` are `runs_code=True` and ship SessionStart/UserPromptSubmit command hooks. They are declared with no `ref` and installed `--scope project` during init (`dummyindex/cli/init.py:73-74`, `dummyindex/installer/install/project_init.py:371-372`), so an upstream push or account takeover runs code in every initialised repo at the next session. The legacy-SHA healer also silently turns a fail-closed 40-hex pin into this latest-tracking form. — **Mitigation:** partial and one-time. `describe_default_plugin_trust` (`:196-214`) prints "tracks latest" and "runs code: yes" plus the `--no-default-plugins` hint, and the `false` tombstone in `_effective_enabled` (`:328`) is honoured; nothing re-checks later. — **Fix:** pin a reviewed tag through the existing `add_marketplace(..., ref=)` (`dummyindex/context/claude_plugins.py:105-118`), and print "unpinned <target>; now tracks latest" on the healing branch.
- `dummyindex/context/domains/equip/models.py:168`, `dummyindex/context/domains/equip/lifecycle/manifest.py:44-45`, `lifecycle/status.py:84-89,112,153,303,344-346,391,409-414`, `lifecycle/remove.py:63-70,98-104`, `lifecycle/evolve.py:45,62` — **Missing:** containment of manifest `path` values. Each verb uses `root / item.path` with no shape check, so an absolute, drive or UNC path (pathlib drops `root`), a `..` path, or an in-repo path such as `.git/...` lets:
  - `reset` overwrite the file (it never calls `classify_item`);
  - `remove --delete-file` delete it, even a user-owned body;
  - `refresh` overwrite any hash-matching file (it runs unattended on reinstall, `dummyindex/installer/install/project_init.py:179,195-211`);
  - `equip uninstall`/`remove` un-wire plugins and marketplaces in the user's global `~/.claude/settings.json`, when a MARKETPLACE record names that file and it holds the key (`dummyindex/context/claude_plugins.py:133-138,165-170`).

  — **Mitigation:** none for `reset`/`remove`. `refresh`/`uninstall` act only when the target's hash equals `origin_hash` (`lifecycle/status.py:161,246-260,378-383`). `is_lifecycle_managed` checks only source, non-empty path and hash presence. `_NAME_RE` confines only the native pointer (`generate/adapters.py:14-30`). — **Fix:**
  - Validate once in `read_manifest` and raise `EquipError`; every caller already catches it.
  - Reject absolute paths, drives, `\` and `..`.
  - Allow only `.context/equipment/<name>.md`, `.claude/agents/<name>.md` and `.claude/skills/<name>/SKILL.md` for bodies, and `.claude/settings.json`, `.claude/settings.local.json` or `""` for marketplace records.
  - Resolve through an equip-local twin of `safe_file` (`dummyindex/context/domains/evolve_gate.py:80-104`).
  - Make `run_reset` write the catalog's rendered path, which `dummyindex/cli/equip/verbs.py:156-158` currently discards.
- `dummyindex/context/claude_settings.py:175-179`, `dummyindex/context/domains/equip/lifecycle/manifest.py:58-68` — **Missing:** a unique temporary file. Both writers open a fixed-name sibling (`settings.json.tmp`, `equipment.json.tmp`) with a truncating `write_text` that follows links, which causes three problems:
  - A repo-committed symlink at that name receives the full settings or manifest payload, and the rename then installs that link as the live file.
  - Concurrent writers interleave into torn JSON that every later write refuses (`claude_settings.py:52-60`, `manifest.py:40-41`).
  - A failed `write_settings` leaves a stray settings copy, including `env`, in `.claude/`.

  — **Mitigation:** none on these two writers. The body-write half is resolved: `_write_file` at `dummyindex/cli/equip/dispatch.py:807-815` now uses `write_text_atomic`. — **Fix:** route both through `atomic_io.write_text_atomic` (`dummyindex/context/domains/atomic_io.py:38-81`). It creates a unique temporary file, retries replace on Windows, and cleans up in `finally`.
- `lifecycle/status.py:303,346,391`, `lifecycle/evolve.py:45-62`, `lifecycle/remove.py:70`, `lifecycle/manifest.py:58-65`, `dummyindex/cli/equip/dispatch.py:714-720`, `dummyindex/context/domains/equip/generate/adapters.py:45-51` — **Missing:** a check for a linked parent directory (`.context/`, `.context/equipment/`, `.claude/agents/`, `.claude/skills/`) in the lifecycle verbs, so the mkdir and rename in `write_text_atomic`, and `unlink`, act inside the link's target tree. On Windows, both `_has_symlink_parent` copies call `Path.is_junction` through a `getattr` fallback; that method only exists from Python 3.12, so on the supported 3.10/3.11 (`pyproject.toml:13`) a junction parent passes the apply guard. — **Mitigation:** apply and adapter paths only, and symlinks only on 3.10/3.11 (`dispatch.py:280-287,483,617-624`, `adapters.py:70,95-98`); none for the lifecycle verbs. — **Fix:** replace both copies with one helper that runs the fail-closed `atomic_io.is_link` on every component from the project root. Call it in `reset`, `refresh`, `uninstall`, `remove_item`, `apply_patch` and `write_manifest` before any write or unlink.
