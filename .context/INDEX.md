## How to use

**Agents:** read `PROJECT.md` for project context, then navigate via `tree.json` and `map/symbols.json` for specific work. Honor `conventions/naming.md` when adding new code.

**Humans:** start with `PROJECT.md`. The `tree.json` and `map/*.json` files are dense — use them programmatically or read sparingly.

## Rebuild vs reconcile

Quick deterministic refresh of the backbone (maps, symbols, graph). It is non-destructive and safe on a curated index: `dummyindex context rebuild --changed`. This refresh is incremental. It never re-clusters curated features. The full re-cluster DISCARDS curation: `dummyindex context rebuild --full`. A bare `dummyindex context rebuild` REFUSES on a curated index and tells you which flag to pass.

To update the index after new or changed code, fold the change into the taxonomy and re-anchor. Run `dummyindex context reconcile` to see the delta since the last reconcile. Then run the reconcile procedure: place new files, re-enrich, and run `dummyindex context reconcile-stamp`. A bare rebuild leaves new files unassigned.
